SC Player+

SoundCloud плеер в стиле Pioneer CDJ: питч-фейдер ±50% и одна точка CUE. Работает через прямой аудио-поток (без embed-виджета).

Плеер не грузит трек? (обновить client_id)

SoundCloud периодически меняет публичный client_id, которым пользуется его собственный сайт. Если загрузка не работает: откройте soundcloud.com в браузере → DevTools → вкладка Network → найдите любой запрос к api-v2.soundcloud.com → скопируйте значение параметра client_id из его URL и вставьте сюда.

Хостится не на localhost? (адрес API-прокси)

Если страница открыта с GitHub Pages / другого домена, а не через node server.js на localhost, укажите здесь адрес развёрнутого Cloudflare Worker (например https://sc-proxy.your-name.workers.dev). Пусто = использовать тот же адрес, с которого открыта страница.
